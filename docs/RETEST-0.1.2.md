# v0.1.2 확인 목록 (약 10분)

v0.1.1에서 안 됐거나 표기가 헷갈렸던 저널 권한 부분만 다시 봅니다. 나머지는 v0.1.1에서 모두 통과했습니다.

## 준비
1. Foundry 설정 화면 → 애드온 모듈 → GM 세션 기록 도우미 → **업데이트** (0.1.2)
2. 테스트 월드 GM 접속 → F12 → Console → 필터 칸에 `gm-session-log` 입력해 둔 채로 진행
3. 새 저널 `권한 테스트3` 만들기: 페이지 1개(본문 아무 글), 저널 기본 권한 **없음**
4. `● 기록 시작` → 이름 아무거나

## 확인

| # | 할 일 | GM 채팅에 생길 줄 | 콘솔에 생길 줄 | 결과 |
|---|---|---|---|---|
| P1 | 사이드바 저널 목록에서 `권한 테스트3` **우클릭 → 권한 설정** → 기본 권한 **관찰자** → 저장 | `저널 권한 공개(관찰자) → 전체(캐릭터): 권한 테스트3` | `권한 변경 감지(저장 전, …): 권한 테스트3` | [ ] |
| P2 | 같은 저널을 다시 **없음**으로 | 줄 **없음** | `…새로 볼 수 있게 된 플레이어 없음…` | [ ] |
| P3 | `두페이지` 저널의 페이지 하나 우클릭 → 권한 설정 → Player2만 관찰자 | `저널 권한 공개(관찰자) → 전체(캐릭터): 두페이지 / (페이지 이름)` (페이지 이름이 저널 이름과 같으면 `두페이지`만) | `권한 변경 감지(저장 전, …)` | [ ] |
| P4 | `백룡` 저널 페이지 Show Players → Player2 | `저널 공유 → 캐릭터만: 백룡` (`백룡 / 백룡`처럼 겹치지 않음) | – | [ ] |

> 테스트 월드에 플레이어가 Player2 한 명뿐이면 "전체(캐릭터)"로 나오는 것이 맞습니다. 플레이어가 여럿인데 일부에게만 열면 `→ 캐릭터만`처럼 나옵니다.

## P1이 또 안 되면
콘솔 필터 칸에 `gm-session-log`를 넣은 상태에서 보이는 줄을 **전부** 복사해서 보내 주세요.
- `권한 변경 감지(저장 전…)` 줄이 **없으면**: Foundry가 권한을 저장하는 경로를 모듈이 못 보고 있다는 뜻입니다.
- `…새로 볼 수 있게 된 플레이어 없음. 전: … / 후: …` 줄이 **있으면**: 감지는 되지만 권한 계산이 다르다는 뜻이고, 그 줄의 전/후 내용으로 원인을 찾을 수 있습니다.

## 그 밖에
- `두페이지` 페이지(지난번 003 파일)가 비어 있던 것이 실제로 본문이 없던 페이지였는지 알려 주세요.
