### 테스트 자료 (GM 창에서 만들기)

| 이름 | 내용 |
|---|---|
| 저널 `백룡 전설 서류` | 텍스트 페이지 1개: 보통 문단 + 그림 1개 + 비밀 블록 2개(`비밀-숨김`, `비밀-공개됨`). `비밀-공개됨`만 **공개(Reveal)** |
| 저널 `두 페이지 문서` | 페이지 2개: `공개쪽`, `비공개쪽`. 저널 기본 권한 **없음** |
| 저널 `권한 테스트2` | 페이지 1개, 기본 권한 **없음** (지난번 `권한 테스트`는 이미 관찰자로 바꿨으므로 새로 만들기) |
| NPC 액터 `고블린 척후병` | 지난번 것 그대로 |

**비밀 블록 만드는 법**
1. 저널 페이지를 편집 화면으로 연다(연필 아이콘).
2. 비밀로 만들 문단을 마우스로 선택한다.
3. 편집기 도구 모음의 서식 드롭다운(보통 맨 왼쪽) → **비밀(Secret)** → 저장.
4. 보기 화면에서 비밀 블록 오른쪽 위에 마우스를 올리면 나오는 **공개(Reveal)** 버튼을 `비밀-공개됨` 블록에만 누른다.

**페이지 추가·페이지별 권한**
1. 저널 창 왼쪽 페이지 목록 아래의 **페이지 추가(+)** 로 페이지를 하나 더 만든다.
2. 페이지 이름 우클릭 → **권한 설정**에서 그 페이지만의 권한을 정한다.

플레이어 창 2개(시크릿 창, 민수·지우)도 지난번처럼 띄워 둡니다.

## H. 많은 양 테스트 (처음 하는 것)

1. `● 기록 시작` → 이름 `대용량`
2. 큰 배틀맵 장면 **3개 이상**을 번갈아 활성화(배경 이미지가 서로 다르게)
3. 매크로로 채팅 300줄 + 주사위 50번 만들기
   - 매크로 막대 빈칸 클릭 → 새 매크로 → 종류 **Script** → 아래 붙여 넣기 → 저장 → 실행
   - GM에게만 보이는 메시지입니다. 끝나면 채팅 지우기로 정리해도 됩니다(추출 뒤에).

```js
// 테스트용: 채팅 300줄(GM 귓속말) + 2d6 굴림 50번
for (let i = 1; i <= 300; i++) {
  await ChatMessage.create({ content: `대용량 테스트 메시지 ${i}`, whisper: [game.user.id] });
}
for (let i = 1; i <= 50; i++) {
  await new Roll("2d6+1").toMessage({ flavor: `테스트 굴림 ${i}` }, { rollMode: "gmroll" });
}
ui.notifications.info("테스트 메시지 만들기 끝");
```
