# FVTT 테스트 절차 (gm-session-log 0.1.0)

소요 시간: 약 40~60분. 각 항목 옆 `[ ]`에 결과를 적어 주세요: ✅ 됨 / ❌ 안 됨(무엇이 보였는지 한 줄).
❌가 나오면 거기서 멈추지 말고 끝까지 진행한 뒤, 표를 통째로 보내 주시면 됩니다.

---

## 0. 준비

### 0-1. 테스트용 월드 만들기 (추천)
테스트 중에 채팅이 수백 줄 생깁니다. 캠페인 월드 채팅이 지저분해지지 않도록 **테스트용 월드**에서 하는 것을 추천합니다.
1. FVTT 설정 화면 → 월드 → 새 월드 만들기 → 시스템: Dungeon World
2. 이름 예: `기록모듈테스트`

### 0-2. 모듈 설치
설치 방법은 둘 중 하나입니다(6단계 배포와 관련, 선택 안내는 보고서 참고).
- **방법 A. manifest 링크 (추천)**: 설정 화면 → 애드온 모듈 → 모듈 설치 → 아래 칸에 링크 붙여 넣기 → 설치
  `https://github.com/Nomal-1/gm-session-log/releases/latest/download/module.json`
- **방법 B. 파일 직접 올리기**: 오라클 서버의 `Data/modules/` 폴더에 `gm-session-log` 폴더를 통째로 올림

설치 뒤:
1. 테스트 월드 실행 → GM으로 접속
2. 게임 설정 → 모듈 관리 → **GM 세션 기록 도우미** 체크 → 저장
3. **플레이어 계정 2개**(예: `민수`, `지우`)를 만들고, 각각에게 캐릭터(예: `카락테르`, `에일린`)를 지정
   - 사용자 설정 → 해당 사용자 → 캐릭터 선택

### 0-3. 플레이어 화면 띄우기
GM 창과 별도로 **시크릿 창 2개**(Ctrl+Shift+N)를 열고, 같은 주소로 `민수`, `지우`로 각각 접속합니다.
세 창을 나란히 두고 진행하면 편합니다.

### 0-4. 테스트 자료 만들기 (GM 창)
| 이름 | 만드는 법 |
|---|---|
| 장면 A `비비안의 저택` | 새 장면, 배경 이미지 아무거나 |
| 장면 B `큰 배틀맵` | 가능하면 4000px 이상 큰 배경 이미지 |
| (선택) 장면 C `움직이는 배경` | 배경에 webm/mp4 동영상 |
| NPC 액터 `고블린 척후병` | 액터 종류 **NPC**, 토큰 이미지와 초상화를 **서로 다른 그림**으로 |
| 저널 `백룡 전설 서류` | 텍스트 페이지 1개. 본문에 ① 보통 문단 ② 그림 1개 ③ **비밀 블록 2개**(편집기 도구의 "Secret"). 그중 하나만 저장 후 보기 모드에서 **공개(Reveal)** 처리. 비밀 블록 안 문구는 `비밀-숨김`, `비밀-공개됨`처럼 알아보기 쉽게 |
| 저널 `두 페이지 문서` | 페이지 2개: `공개쪽`(권한: 관찰자), `비공개쪽`(권한: 없음). 저널 전체 기본 권한은 없음 |
| 저널 `권한 테스트` | 페이지 1개, 기본 권한 없음 |

## H. 많은 양 테스트

실제 세션만큼 채팅과 큰 이미지가 쌓였을 때 끝까지 추출되는지 봅니다.

1. GM: `● 기록 시작` → 이름 `대용량`
2. 큰 배틀맵 장면을 **3개 이상** 번갈아 활성화(각각 배경 이미지가 다르게)
3. 아래 매크로로 채팅 300줄 + 주사위 50번 만들기
   - 매크로 막대 빈칸 클릭 → 새 매크로 → 종류 **Script** → 아래 내용 붙여 넣기 → 저장 → 실행
   - 만든 메시지는 GM에게만 보이는 귓속말입니다. 나중에 채팅 지우기로 정리하면 됩니다.

```js
// 테스트용: 채팅 300줄(GM 귓속말) + 2d6 굴림 50번
for (let i = 1; i <= 300; i++) {
  await ChatMessage.create({ content: `대용량 테스트 메시지 ${i}`, whisper: [game.user.id] });
}
for (let i = 1; i <= 50; i++) {
```
