# GM 세션 기록 도우미 (gm-session-log)

Foundry VTT v12용 **GM 전용** 모듈입니다. 던전월드 캠페인에서 세션이 끝난 뒤 AI로 세션 로그를 정리할 때 쓸 원자료를 만듭니다.

- **화면 사건 기록**: 장면 전환, 이미지·저널 공개, 저널 권한 공개, NPC 토큰 등장을 GM에게만 보이는 귓속말로 남깁니다.
- **세션 구간 표시**: 채팅 탭 맨 위의 `● 기록 시작` / `■ 기록 종료` 버튼으로 녹음 파일과 시간을 맞춥니다.
- **세션 기록 추출**: 기록 구간의 채팅 전체와 플레이어에게 보여준 자료를 zip 하나로 내려받습니다.

플레이어 화면에는 아무것도 바뀌지 않습니다. 채팅·저널·장면·이미지는 읽기만 하고 수정하거나 삭제하지 않으며, 외부 서버로 데이터를 보내지 않습니다.

## 설치
1. Foundry 설정 화면 → **애드온 모듈** → **모듈 설치**
2. 맨 아래 manifest 칸에 붙여 넣고 설치:
   ```
   https://github.com/Nomal-1/gm-session-log/releases/latest/download/module.json
   ```
3. 월드 실행 → 게임 설정 → 모듈 관리 → **GM 세션 기록 도우미** 체크

- 대상: Foundry VTT v12 (검증 12.331), Dungeon World 시스템 1.8.2
- 다른 라이브러리 모듈이 필요 없습니다.

## 세션 당일 사용 순서
1. 디스코드에서 **Craig 녹음 시작**
2. FVTT 채팅 탭 위 **`● 기록 시작`** → 세션 이름 입력(비우면 날짜) → 막대가 빨간색으로 바뀜
3. 세션 진행
4. **`■ 기록 종료`** → "지금 추출할까요?" → **예** → zip 내려받기
5. 디스코드에서 **Craig 녹음 정지** → 음성 다운로드
6. 받아쓰기 텍스트 + zip을 AI에게 주고 세션 로그 초안 만들기

예비용 채팅 명령: `/기록시작 [이름]`, `/기록종료`, `/기록추출` (GM만)

## 내려받는 zip
```
세션기록_2026-10-10_레이븐홀트3.zip
├─ 세션기록.md     시간순 기록 (시각, 기록 시작 후 경과 시간, 말한 사람, 종류, 내용, 판정 10+/7-9/6-)
├─ 자료목록.md     보여준 자료 표 (번호, 종류, 이름, 공개 대상, 보여준 시각, 파일)
└─ 자료/           장면 배경, 공개 이미지, NPC 토큰·초상화, 저널(.md + 그림)
```
- 저널은 **보여준 순간 플레이어가 볼 수 있던 부분만** 들어갑니다. 공개(Reveal)하지 않은 비밀 블록과 권한 없는 페이지는 빠지고, 뺀 개수만 적힙니다.
- 같은 자료를 여러 번 보여줬으면 파일은 하나, 시각은 모두 적힙니다.
- 이미지는 기본적으로 긴 변 1600px webp로 줄입니다. 동영상·GIF·SVG는 원본 그대로 넣습니다.

## 설정 (게임 설정 → 설정 구성 → 모듈 설정, GM만)
| 항목 | 기본값 | 설명 |
|---|---|---|
| 모듈 사용 | 켜짐 | 끄면 버튼·기록·명령이 모두 멈춤 |
| 기록: 장면 전환 / 이미지 보여주기 / 저널 보여주기 / 저널 권한 공개 / NPC 토큰 등장 | 모두 켜짐 | 사건 종류별 켜기·끄기 |
| 기록 중일 때만 화면 사건 기록 | 켜짐 | 세션 준비 중 사건이 섞이지 않게 함 |
| 추출 이미지 저장 방식 | 축소 | 축소(1600px webp) / 원본 유지 |
| 추출에 JSON 함께 넣기 | 꺼짐 | zip에 `세션기록.json` 추가 |

## 알려진 한계
- Foundry는 GM 귓속말도 모든 사람의 브라우저에 보내고 화면에만 숨깁니다. 그래서 플레이어가 개발자 콘솔(F12)에서 직접 명령을 입력하면 기록 줄과, 다른 플레이어에게만 보여준 저널의 공개분을 읽을 수 있습니다(일반 화면에는 절대 보이지 않음).
- 기록 줄은 채팅 메시지이므로, 채팅 로그를 지우면 그 구간은 추출할 수 없습니다. 추출을 먼저 하세요.
- 액터 초상화는 참고용으로 넣으며, 플레이어가 실제로 보지 못했을 수 있습니다(`초상화(참고)`로 표시).
